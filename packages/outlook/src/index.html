Hanzo AI for Outlook

Summarize threads, draft replies and pull out action items. Add it with this manifest: https://outlook.hanzo.ai/manifest.xml

  • Outlook on the web: Settings → Get Add-ins → My add-ins → Add a custom add-in → Add from URL, and paste the manifest link above.
  • Your whole organization: Microsoft 365 admin center → Settings → Integrated apps → Upload custom apps → provide the manifest link above.
